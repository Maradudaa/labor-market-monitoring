# labor-market-monitoring
Прогнозно-аналитическая система мониторинга изменения динамики вакансий рынка труда

## Цель проекта

Разработка прогнозно-аналитической системы для мониторинга динамики вакансий российского рынка труда и прогнозирования изменения их количества.

## Прогнозируемый показатель

Количество опубликованных вакансий за заданный период времени.

## Источники данных

1. Исторический набор данных вакансий hh.ru за 2023 год.
2. API hh.ru для регулярного получения актуальных данных о вакансиях.

## Планируемые компоненты системы

- загрузка исторических данных;
- получение актуальных данных через API hh.ru;
- хранение и обработка данных;
- аналитика динамики вакансий;
- прогнозирование;
- визуализация результатов.
